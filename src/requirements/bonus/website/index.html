System Administration

Reglas de Oro del Subject

  • Prohibido usar network: host o enlaces rápidos. Debes configurar una red propia (Tiers).
  • Prohibido usar el comando tail -f para mantener vivos los contenedores en los entrypoints.
  • Todos los contenedores deben compilarse desde su propio Dockerfile hecho desde cero (Base: Alpine o Debian).
  • Docker Compose debe estructurarse obligatoriamente en srcs/docker-compose.yml.
  • Volúmenes persistentes mapeados obligatoriamente a /home/usuario/data/....

Comandos Críticos de Depuración

Construir y levantar todo el entorno en segundo plano:

docker compose -f srcs/docker-compose.yml up --build -d

Verificar el estado de las redes creadas por ti:

docker network ls && docker network inspect [nombre]

Entrar de forma interactiva a un contenedor para verificar paquetes:

docker exec -it nginx sh

Limpieza absoluta del sistema (útil para reiniciar en la evaluación):

docker system prune -a --volumes
